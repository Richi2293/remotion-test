# RicDev YouTube Intro — Prompt Brief

## Common

- **Channel**: RicDev
- **Fixed element**: "RicDev" text (always present)
- **Duration**: 7 seconds (420 frames @ 60fps)
- **Resolution**: 1920x1080
- **Phases**: Entry (0-2s) → Body (2-5s) → Exit (5-7s)
- **No profile photo** — text, shapes and animations only
- **Context**: Italian freelance dev channel — coding with AI, modern stacks (Next.js, React Native, NestJS), real production code, no fluff

---

## Style 1: Minimal Terminal

**Mood**: Authentic dev, zero fluff, straight to the point.

**Palette**:
- Background: #0d1117 (GitHub dark)
- Primary text: #e6edf3 (white-ish)
- Accent: #3fb950 (terminal green)
- Cursor: #58a6ff (blue)

**Font**: JetBrains Mono or Fira Code (monospace)

**Animation phases**:
- **Entry (0-2s)**: Black screen. A terminal prompt `>_` blinks on. Characters of "RicDev" are typed one by one with a blinking cursor, like a real terminal.
- **Body (2-5s)**: "RicDev" fully visible. Subtle scanline effect across the screen. A faint `$ npm run dev` line appears below, then a green "ready" status fades in. Cursor keeps blinking.
- **Exit (5-7s)**: Everything fades out, cursor blinks one last time and disappears.

**References**: VS Code terminal, GitHub dark theme, old-school CRT monitors.

## Style 2: Glitch / Cyber

**Mood**: Edgy, hacker vibe, tech YouTube energy.

**Palette**:
- Background: #000000
- Primary text: #ffffff
- Glitch colors: #ff0040 (red), #00ff88 (green), #4040ff (blue)
- Accent flash: #ff6600

**Font**: Bold sans-serif (Inter Black or similar), wide letter-spacing

**Animation phases**:
- **Entry (0-2s)**: Black screen. Quick RGB displacement flashes. "RicDev" slams in with a hard glitch — text splits into R/G/B channels offset horizontally, then snaps together.
- **Body (2-5s)**: "RicDev" stable but with periodic micro-glitches (random horizontal displacement of text slices every ~0.8s). Faint horizontal scanlines scroll slowly across the screen. A subtle digital noise grain in the background.
- **Exit (5-7s)**: One final hard glitch, text corrupts and dissolves into pixel fragments that scatter.

**References**: Cyberpunk aesthetics, MKBHD glitch transitions, VHS distortion.

## Style 3: Modern Motion

**Mood**: Clean, professional, SaaS/startup feel.

**Palette**:
- Background gradient: #0f0c29 → #302b63 → #24243e (deep purple)
- Primary text: #ffffff
- Accent shapes: #6c63ff (purple), #00d2ff (cyan)
- Glow: rgba(108, 99, 255, 0.4)

**Font**: Inter or Geist Sans, weight 800, wide letter-spacing

**Animation phases**:
- **Entry (0-2s)**: Soft gradient background fades in. Geometric shapes (circles, rounded rectangles) float in from edges with spring physics — they're blurred and serve as decorative bokeh.
- **Body (2-5s)**: "RicDev" scales up from 0 with a spring animation (slight overshoot). Subtle glow pulses around the text. The background shapes drift slowly, creating depth. A thin accent line draws itself under the text.
- **Exit (5-7s)**: Everything scales down slightly and fades to black. Shapes drift outward.

**References**: Linear.app, Vercel landing pages, modern SaaS product videos.

## Style 4: Code Flow

**Mood**: "This channel is about real code." Technical, authentic, dev-focused.

**Palette**:
- Background: #1a1a2e (dark navy)
- Code text: #8b949e (muted gray, like comments)
- Primary text: #ffffff
- Syntax highlights: #ff7b72 (red/keywords), #79c0ff (blue/strings), #7ee787 (green/functions)
- Glow: rgba(126, 231, 135, 0.3)

**Font**: JetBrains Mono for code, Inter Bold for "RicDev"

**Animation phases**:
- **Entry (0-2s)**: Lines of real code (React/Next.js snippets) scroll vertically in the background, blurred and at low opacity. They come from multiple columns at different speeds, like a rain of code.
- **Body (2-5s)**: The code rain slows. "RicDev" fades in at center with a soft green glow, sharp and in focus — contrasting with the blurred code behind it. A subtle light sweep crosses the text left to right.
- **Exit (5-7s)**: "RicDev" fades out, code lines accelerate and fade to black.

**References**: Matrix (but tasteful), GitHub contribution graph colors, VS Code syntax themes.
